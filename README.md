# HenriqueSFernandes Tap

## How do I install these formulae?

`brew install henriquesfernandes/tap/<formula>`

Or `brew tap henriquesfernandes/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "henriquesfernandes/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
